# Marcel au Comptoir

Site vitrine du restaurant **Marcel au Comptoir**, 17 avenue Notre-Dame, 06000 Nice.

Page unique en français et en anglais : présentation, carte, accès et horaires.

## Structure

- `index.html` : le site (HTML, CSS et JS dans un seul fichier)
- `assets/img/` : photos
- `assets/fonts/` : polices Big Shoulders Display, Caprasimo et Instrument Sans (licence SIL Open Font License)

## À compléter

- La carte : remplacer les `[Nom du plat]`, `[Courte description]` et `[Prix]` dans `index.html`
  (et la version anglaise dans l'objet `EN` du script en bas de page)
- Les horaires du dimanche

## Crédits photos
